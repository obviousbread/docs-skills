# Проверка данных в интернете

Используй поиск только для изменяемых или отсутствующих фактов.

1. Сначала ищи первичный официальный источник; для НПА — официальный портал опубликования или сайт органа.
2. Подтверди точные реквизиты, статус и применимость минимум одним надёжным источником.
3. Зафиксируй `source_url`, `checked_at` и `confidence`.
4. Полный текст открывай, когда нужна конкретная статья, пункт или дословная формулировка.
5. При конфликте источников покажи расхождение пользователю.
6. Если подтверждения нет, верни «не найден» и не выдумывай.
