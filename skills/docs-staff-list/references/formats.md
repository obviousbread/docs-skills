## Автоопределение

`detect_format()` анализирует первые строки каждого файла и выбирает один из трёх парсеров. Имя файла не определяет формат.

Если probe показывает ноль строк или явно неверный формат, сначала проверить структуру первых 15 строк, затем применить узкое переопределение. Новый парсер добавлять только для структуры, которая не входит ни в одно существующее семейство.

## shtatnaya

Иерархическая штатная расстановка.

Признаки:

- ячейка `Позиция`; или
- заголовок, начинающийся с `Сотрудник,`;
- строки подразделения, должности и сотрудника чередуются;
- сотрудник обычно определяется по заполненной дате рождения.

Поддерживаются:

- полная дата рождения в отдельной колонке;
- только год рождения;
- год в значении ФИО вида `Тестов Т.Т., 1977`.

## table

Плоская таблица с заголовком `Сотрудник`/`ФИО` и колонками должности, даты рождения или подразделения. Позиции колонок могут отличаться.

Режимы:

- `dept-as-column`: подразделение находится в отдельной колонке; каждая строка описывает сотрудника;
- `dept-as-separator`: подразделения находятся в строках-разделителях, а строки сотрудников имеют номер.

Если в таблице есть колонка `Филиал`, использовать её. Пустую ячейку в этой колонке
не заполнять догадкой из имени сводного файла. В режиме `dept-as-column` пустое
подразделение не наследуется из предыдущей строки.

Сохраняются все дополнительные колонки и их значения, включая текстовые
идентификаторы с ведущими нулями. Несколько файлов дают объединение их колонок;
отсутствующие в конкретном файле поля остаются пустыми. Дополнительные поля
`Место рождения` и `Код подразделения` не являются датой рождения и подразделением.

Двухъярусная шапка распознаётся по строке подзаголовков без ФИО и основных полей.
В выходе используется один ряд листовых заголовков: например, группа
`Удостоверение личности` с полями `Вид`, `Серия`, `Номер` становится тремя колонками
с этими названиями. Повторяющиеся названия уточняются группой. Пустые колонки,
созданные горизонтальными объединениями, пропускаются; безымянная колонка с
данными сохраняется как `Колонка N`.

Строки-продолжения с дополнительной должностью и пустым ФИО пропускаются и
учитываются в отчёте. Если эти строки нужны по запросу, отдельно разобрать их
перед консолидацией, не считать пропущенные значения отсутствующими в источнике.

## split_fio

Фамилия, имя и отчество находятся в отдельных колонках. Заголовки могут быть явными; для старых таблиц также поддерживается последовательность `№ | Фамилия | Имя | Отчество | дата | должность` без заголовка.

При явных заголовках исходные части ФИО и дополнительные поля сохраняются в их
порядке; объединённое поле `Сотрудник` добавляется для использования списка другими
документными навыками.

## Переопределения

```bash
--format-map "file.xls:shtatnaya"
--year-only "file.xlsx"
--date-col "file.xls:4"
--branch-map "file.xls:Филиал А"
```

Допустимые форматы: `shtatnaya`, `table`, `split_fio`. Индекс `--date-col` начинается с нуля.

## Очистка ФИО

`clean_fio()` удаляет:

- пометки о внешнем и внутреннем совместительстве;
- статусы работы, болезни и отпусков;
- прочие служебные скобочные пометки;
- лишние слова после базового ФИО с учётом частиц `оглы`, `кызы`, `де`, `фон`, `ван`.

Короткие служебные суффиксы `осн`, `внешн.`, `совм`, `СТД` удаляются и из ФИО без
отчества. Недостающие части ФИО не достраиваются. Все изменения печатаются в отчёте
и требуют проверки текста до и после, без обязательного рендеринга книги.
