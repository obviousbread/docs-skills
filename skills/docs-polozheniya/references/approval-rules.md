# Утверждение и согласование

## Утверждение

Положение является завершенным документом и содержит собственный гриф `УТВЕРЖДАЮ`. По умолчанию документ утверждает руководитель организации из `org_details.md`.

Используй:

- `leader_title` — должность в грифе;
- `leader_name_nom` — расшифровка подписи;
- `leader_title_gen` и `leader_title_ins` — падежные формы внутри текста.

Не создавай отдельный приказ об утверждении без прямого запроса пользователя.

## Согласование

Состав согласующих определяется реальной иерархией и правилами организации. Типовая последовательность, если подтверждена источниками:

1. Курирующий руководитель.
2. Руководитель вышестоящего подразделения.
3. Руководитель подразделения — разработчика проекта.
4. Руководитель кадрового подразделения.

Перед генерацией:

- найди должности и ФИО в итоговых документах или `staff_file`;
- не подставляй найденного по приблизительному совпадению сотрудника автоматически;
- при расхождении источников покажи его пользователю;
- неизвестное ФИО оставь пустым только после подтверждения пользователя.
